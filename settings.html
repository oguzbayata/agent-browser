Agents

Multi-agent bridge

Let local agents drive the browser freely. Loopback only (127.0.0.1). The token stays in RAM.

Example: Authorization: Bearer <token> and POST /v1/tabs {"url":"https://duckduckgo.com","owner":"agent-1"}

Search: GET /v1/settings, POST /v1/settings {"searchEngine":"google"} or {"searchEngine":"bing","scope":"session"}, POST /v1/search {"query":"weather","searchEngine":"yahoo"}, POST /v1/tabs {"query":"maps","searchEngine":"naver"}
